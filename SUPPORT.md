# Support

SELMA Labs is an early-stage open-source project and does not provide an
emergency or guaranteed-response support service.

Before opening an issue:

1. Read the [documentation index](docs/README.md) and [runbook](RUNBOOK.md).
2. Run `python scripts/system_health.py --profile factory`.
3. Search existing issues for the same symptom.
4. Choose the issue form that best matches the problem.

Use the provider/runtime form for ComfyUI, FFmpeg, GPU, model, API, or local
environment setup problems. Use the bug form for reproducible product defects
and the feature form for proposals.

Redact tokens, credentials, personal paths, private media, and identifying data
from logs and screenshots. Security vulnerabilities must be reported through
the private process in [SECURITY.md](SECURITY.md).
